# Use this kit with your AI assistant

This kit holds YWCA Knoxville's colors, type rules, page parts, writing rules and privacy rules.

It also has a Power BI theme, which is a file that sets the colors and fonts for a report.

Give it to your AI chat assistant. Then your flyer, slide, chart or web page can look and sound like YWCA.

It works with Claude, ChatGPT, Microsoft Copilot, Gemini, or any other assistant.

**Please read this first.** This kit is an unofficial draft that YWCA has not reviewed, and where the kit and YWCA staff disagree, staff are right.

The Power BI theme file has not been tested in Power BI Desktop yet.

## Quick start

The whole kit is in one file, named `YWCA-DESIGN-KIT.md`. It is plain text.

1. **Get the one file.** Open [`YWCA-DESIGN-KIT.md`](YWCA-DESIGN-KIT.md) in this repository, which is the online folder that holds the kit. Save a copy, or copy all of its text.

2. **Give it to your assistant.** Start a new chat, then attach the file to your message, or paste its text in.

3. **Ask for what you need.** Say what you want, and tell the assistant to follow the kit.

That is the whole method.

**A time saver.** Many assistants let you save a file or a set of instructions, so you do not have to attach it each time. If yours does, save the kit there once.

**In a new chat.** Give the assistant the file again, unless you saved it as described above.

## Starter prompts

A prompt is the message you type to your assistant.

Copy one of these. Swap the words in [square brackets] for your own. Send it in a chat that has the kit.

**1. A chart title**

```
Follow the design kit I gave you. Write a title for a chart that shows this: [say what the chart shows, in your own words]. The title must state the one point of the chart in plain words.
```

**2. A one-page program summary for a funder**

```
Follow the design kit I gave you. Draft a one-page summary of [program name] for a funder, using the kit's fact sheet layout and its voice rules. Write [NUMBER] wherever you need a number from me, and do not make any up.
```

**3. A slide**

```
Follow the design kit I gave you. Plan a title slide for a talk called [title of your talk]. List what goes where, and give the color, font and size of each line of text.
```

**4. A social post**

```
Follow the design kit I gave you, including its voice rules. Write a [Facebook] post about [your news or event]. End with one clear next step for the reader, and use no emoji.
```

**5. Check a draft against the voice rules**

```
Check my draft against the voice rules in the design kit I gave you. List each place it breaks a rule, name the rule, and suggest a fix. Here is my draft: [paste your draft]
```

**6. Pick the right logo file**

```
Using the design kit I gave you, tell me which logo file to use on [a white page, a black slide, a persimmon flyer, or a photo]. Tell me the smallest size and the clear space the kit asks for.
```

**7. A Power BI page layout**

```
Follow the Power BI rules in the design kit I gave you. Plan one report page that answers this question: [your question]. Tell me what goes in each zone of the page, and write the page title and each chart title.
```

**8. Alt text for a photo**

```
Follow the design kit I gave you. Write alt text for a photo that shows [describe the photo in a few words]. Alt text is the short description read aloud to someone who cannot see the photo.
```

## Check its work

Assistants are fast and sure of themselves. They are also sometimes wrong.

Check these five kit rules every time.

- **Persimmon text must be big.** Persimmon is the kit's signal color. It is for text only at 24px and up, or bold text at 19px and up. (px means pixels, the dots on a screen.)

- **One persimmon bar per chart.** The bar or line that carries the point is persimmon, and the rest are gray.

- **Never "the YWCA".** The kit says to write "YWCA" every time.

- **Counts under five stay hidden.** Any count below five is hidden, and "Fewer than 5" shows in its place.

- **No words across a face.** In a photo, words never cross a face.

If the assistant missed one, tell it which rule, and ask it to fix the work.

**One more, about pictures.** Do not ask an assistant to make pictures of people for YWCA. The kit says to use only photos YWCA supplies, and never to show a program participant.

## Keep people safe

Never paste resident names, records or export files into an AI assistant. Many women in YWCA programs are survivors of domestic violence, so their safety comes first.
