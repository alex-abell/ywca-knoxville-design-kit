# Power BI theme

`ywca-knoxville-theme.json` is a Power BI report theme built from this kit's tokens.

To use it: in Power BI Desktop, open the View tab, choose Themes, then Browse for themes, and pick this file.

It has not been tested in Power BI Desktop yet. Check it on first import.

The Keys of Hope report built at Hack for Nonprofits 2026 uses its own simpler theme with the same persimmon and black. It does not use this file yet.
