# Photos

This folder is empty on purpose.

The kit was built from six banner photos on ywcaknox.com. They are YWCA's photos, and nobody
has confirmed they are licensed for new uses, so they are not in this repo. The component
previews show a plain gray placeholder where a photo goes.

Rules for any photo you add:

- Use only photos YWCA supplies. Never show a program participant.
- Store the photo as a normal, untinted file. The persimmon wash comes from the `PhotoBand` CSS.
- Words never cross a face. A logo never crosses a face.
- Write alt text for every photo that carries meaning.

The full rules are in `guides/brand-rules.md` under "Imagery".
